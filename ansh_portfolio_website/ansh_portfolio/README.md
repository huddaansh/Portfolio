# Ansh Hudda Portfolio

A responsive portfolio concept for showcasing software development and data analytics work. Built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styles, and visual effects
- `script.js` — mobile navigation and current copyright year

## Run locally
1. Download or extract this folder.
2. Open it in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Personalize before publishing
- Update the About section to reflect your real experience.
- Replace sample dashboard/API cards with projects you have actually completed.
- Update GitHub, LinkedIn, and email links.
- Add real screenshots and project repository links.
- Keep only skills you can confidently discuss.

No build step is required. Google Fonts are loaded from the web; the page uses fallback fonts if they are unavailable.
